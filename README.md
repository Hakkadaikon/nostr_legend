# 伝説の年表

Nostr ユーザーの過去1年分の投稿をもとに、その人を伝説の人物に見立てた年表サイトを作るツールです。
日ごとの出来事を three.js の螺旋に並べて表示します。
螺旋はおよそ1か月で1周し、光の玉が1日を表します。
玉を選ぶと、その日の出来事が箇条書きで表示されます。

公開鍵を指定すれば、誰の年表でも作れます。
ただし実在の人物を面白おかしく扱うサイトなので、作成や公開の前に本人の了解を取ってください。

## 必要なもの

- Node.js 22 以降（投稿の取得にネイティブ WebSocket を使います）
- pnpm

```sh
pnpm install
```

## データの準備

投稿データ（`data/posts.json`）と年表データ（`data/timeline.toml`）はリポジトリに含めていません。
サイトはビルド時に `data/timeline.toml` を読み込むため、先に次の手順で用意します。

### 1. 投稿を取得する

対象ユーザーの公開鍵（`npub1` で始まる文字列）を引数に渡します。

```sh
pnpm run fetch:posts npub1xxxxxxxx
```

実行時点から365日前までの kind 1 の投稿を取得し、投稿日時の昇順に並んだ JSON 配列として `data/posts.json` に保存します。

取得先のリレーは `--relay` で指定でき、複数回書けば複数のリレーから取得します。
省略したときは wss://yabu.me と wss://relay.ditto.pub を使います。

```sh
pnpm run fetch:posts npub1xxxxxxxx --relay wss://relay.example.com --relay wss://relay2.example.com
```

続きだけ取りたいときは `--since YYYY-MM-DD`（JST の0時）を付けます。
その日以降の投稿だけを取得し、既存の `data/posts.json` に追加します。
取得後は `pnpm split` で月ごとのテキストを作り直し、新しい日の分だけ要約して統合し直します。

```sh
pnpm run fetch:posts npub1xxxxxxxx --since 2026-10-02
```

リレーに負荷をかけないよう、取得は次の条件で行います。

- **直列**：リレーを1つずつ順に処理し、同時に開く接続は1本だけにする
- **間隔**：1回の要求は最大500件とし、要求の間に2秒待つ
- **上限**：1リレーあたり最大100回の要求で打ち切る

`pnpm fetch` は pnpm の組み込みコマンドと名前が重なるため、`pnpm run fetch:posts` で実行してください。

### 2. 月ごとのテキストに分ける

```sh
pnpm split
```

`data/posts.json` を JST の日付ごとにまとめ、`tasks/summary/input/YYYY-MM.txt` に月単位で書き出します。
出力先は引数で変えられます。

### 3. AI で要約する

月ごとのテキストを AI に読ませ、日ごとの出来事を箇条書きにした TOML を `tasks/summary/output/YYYY-MM.toml` に書かせます。
形式は次のとおりです。

```toml
[[days]]
date = "2026-07-01"
events = [
  "新たなる AI の眷属を召喚し、その実力を見極める",
]
```

`date` は必ずダブルクォートで囲んだ文字列にします。
クォートしないと TOML の日付型として読まれ、読み込み時にエラーになります。

AI に指示するときは、本人を伝説の人物として誇張しつつ、元ネタは必ずその日の実際の投稿にするよう求めます。
公開を前提にするなら、病気や服薬、家族の私事、第三者の実名などは年表に入れないよう指示してください。
投稿自体は公開されていても、まとめて笑いの種にすると本人に実害が出ることがあります。

### 4. 年表をまとめる

`--name` に年表の主役の名前を渡します。

```sh
pnpm merge --name 名前
```

`tasks/summary/output/` の TOML をすべて読み、同じ日付の項目を結合して `data/timeline.toml` に書き出します。
名前は画面中央で回る 3D 文字になり、タイトルは「伝説の男・名前の年表」になります。

タイトルは `--title` で変えられ、入力ディレクトリは引数で変えられます。

```sh
pnpm merge --name 名前 --title "伝説の名前" path/to/output
```

## サイトの起動とビルド

```sh
pnpm dev                     # 開発サーバー
pnpm build && pnpm preview   # 本番ビルドの確認
```

ビルド結果は `dist/` に出力されます。
静的ファイルだけで動くので、任意の静的ホスティングに置けます。

## 操作

- **玉をクリック、またはタップ**：その日へカメラが移動し、出来事の一覧が開く
- **玉にマウスを重ねる**：日付と最初の出来事を表示する
- **月のボタン**：その月の最初の日へ移動する
- **検索欄**：入力した語を含む日だけを光らせる
- **左右の矢印キー**：前後の日へ移動する
- **スペースキー**：日を順に巡る自動再生を開始、停止する
- **ドラッグ**：視点を回転する

## テスト

```sh
pnpm test
```

## 構成

| パス | 内容 |
|---|---|
| `src/nostr.ts` | npub の変換、取得のページ送り、リレーへの問い合わせ |
| `src/cli.ts` | 取得とまとめのコマンド引数の解釈 |
| `src/timeline.ts` | JST の日付への変換、日ごとのまとめ、TOML の読み書き |
| `src/layout.ts` | 螺旋上の座標、月ごとの区切り、検索の一致判定、画面上での玉の選択 |
| `src/main.ts` | three.js の描画と画面操作 |
| `scripts/` | 取得、分割、統合の各コマンド |
| `test/` | vitest のテスト |
